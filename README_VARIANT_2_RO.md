# AetherTrigger v1.1 — Logo Variant 2 / Typography

## Decizia aprobată
- **Logo:** varianta 2 aleasă în conversație, păstrată pixel-cu-pixel în `public/logos/aethertrigger-v2-approved-original.png`.
- Versiune optimizată, proporțională, fără redesenare: `public/logos/aethertrigger-emblem-v2.png`.
- Logo site: imagine aprobată + text HTML real „AETHER TRIGGER” (accesibil și adaptabil pe mobil).
- **Font pentru nume/titluri: Sora, 700–800.**
- **Font pentru navigație/body: Manrope, 400–700.**
- Fonturile sunt încărcate prin Google Fonts CDN la vizitarea site-ului; există fallbacks. Politica de confidențialitate menționează furnizorul.
- Sigla din mockup este un PNG transparent autentic, NU un fișier vectorial; nu este prezentată în mod fals ca SVG.
- Favicon, Apple touch icon, OG image și `ImageObject` din graph au fost actualizate.
- Cele 7 pagini, sloganul exact și toate footer-linkurile către Quant Data Intelligence LLC sunt păstrate.

## Publicare
Instalați dependențele și rulați `npm run build`; pentru Vercel, importați sursa ca proiect Next.js separat.

## Observație vizuală
Sora/Manrope se vor afișa exact când încărcarea Google Fonts este disponibilă; la lipsa conexiunii se folosește Inter/Arial.
